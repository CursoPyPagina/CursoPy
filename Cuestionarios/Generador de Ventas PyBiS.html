Generador de ventas

Un script que inventa días completos de ventas de una papelería, los arma en un DataFrame y los guarda en la base Ventas.db. Con él tienes miles de registros listos para practicar consultas SQL y armar tableros en Power BI.

Las 4 funciones del script

Cada función hace una sola tarea. Las dos de generación se apoyan en las otras: primero creas un día, luego un rango completo, y al final consultas lo que guardaste.

generar_df_info(fechaVenta, ifExists)

Genera entre 1,000 y 35,000 ventas al azar para un día: cajero, producto, precio, cantidad, total y sucursal. Arma el DataFrame y lo sube a la tabla Ventas_2025.

to_sql
consulta(query)

Abre la conexión a Ventas.db, ejecuta la consulta SQL que le pases y te regresa el resultado como DataFrame de Pandas.

read_sql_query
rangoFecha(fechaInicial, fechaFinal)

Crea la lista de días entre dos fechas con pd.date_range y convierte cada una a texto con el formato AAAA-MM-DD.

date_range · strftime
generar_df_info_rango(fechaInicial, fechaFinal)

Recorre cada día del rango y llama a generar_df_info con "append", así las ventas se van sumando a la tabla en lugar de reemplazarse.

for · append
