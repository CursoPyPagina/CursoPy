Descripción: En este curso buscaremos aprender cuatro de las tecnologías más demandadas en el mercado laboral entorno a los datos, para lo cual:

  1. Python + SQL: Aprenderemos estos dos lenguajes de programacación para montar y automatizar un flujo de datos.

    Parte II

    En la parte anterior logramos generar y mostrar un ticket de venta, con lo cual prácticamente ya tenemos el núcleo de información para poder desarrollar nuestro proyecto. Así, lo que haremos en esta parte será ahora, en vez de generar tickets, generar la información suficiente para crear nuestro primer dataframe sobre la ventas de un día en particular en nuestra papelería y automatizar la carga a nuestra base de datos. Para lo cual

    • Definiremos listas vacías, las cuales posteriormente se irán llenando dentro de un bucle for.
    • Dentro del bucle for utilizaremos la librería random y sus distintas funciones para generar/seleccionar: una sucrusal, un producto, una clave del producto, precio, cantidad vendida y el total.
    • Posteriormente, con base en las listas previamente llenadas, definiremos un dataframe.
    • Luego, agregaremos el código necesario para alimentar la base de datos usando el dataframe del punto anterior. Para tal tarea, necesitaremos de los conceptos de: f-string, loc[] de pandas, INSERT INTO de SQL.
